Design rationale

Rule-based scorers run always — they're free and deterministic. The judge is additive, for what rules can't catch. Composite weighting reflects real operational cost: a missed escalation or a hallucinated feature is a customer-facing incident; a wrong category is a routing nuisance.

What's swappable

The dataset (drop in real tickets via --test-cases). The model (--model, 8 variants pre-priced). The judge (--judge-model — use a stronger model to reduce self-agreement bias). The strategies (add a function to STRATEGIES).

Runtime · Cost

Full eval: 160 API calls, ~3 minutes, ~$0.40 on Sonnet 4.
With judge: ~320 calls, ~$0.80.
Tests: 43/43, 2 seconds, no API calls.
